# v0.1.0

First public release of BatteryNag Audit.

- Samples macOS and Linux battery/power state using built-in interfaces.
- Highlights observed source transitions and expected low-battery conditions.
- Supports bounded multi-sample observation and JSON output.
- Remains fully read-only: no notification dismissal, settings changes, telemetry, or network access.
- Includes deterministic tests and macOS/Linux CI.
